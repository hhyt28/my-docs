# hyt 的开源实践笔记

欢迎来到我的技术文档网站。我是 **hhyt28**，这里记录《开源软件构建技术》课程中，从编写 Markdown 到自动发布网站的实践方法。

## 从一次修改开始

这个项目关注一个具体问题：修改文档后，如何让读者访问到最新内容？我采用“版本管理、自动构建、在线发布”的流程，把重复操作交给 GitHub Actions，让每次修改都有记录，也能从日志中找到失败原因。

```text
修改 docs/*.md → 推送到 main → Actions 构建 site/ → Pages 发布 → 访问网站
```

## 学习重点

我希望通过这次实践理解源码与网站的区别：Markdown 是可维护的输入，HTML 是构建后的输出；真正让网站持续更新的是两者之间的自动化流程。API 页面只是接口说明示例，本项目不提供后端服务。
