# 关于本项目

## 项目目标

搭建一个结构清楚、可以重复构建的个人文档站，并通过 GitHub 官方 Pages Actions 工作流完成发布。这是个人课程作业，仓库所有者为 **hhyt28**。

## 工具如何配合

| 工具或目录 | 职责 | 是否手工维护 |
| --- | --- | --- |
| Markdown / docs/ | 保存四页正文 | 是 |
| mkdocs.yml | 配置主题、导航和网站地址 | 是 |
| MkDocs Material | 将 Markdown 渲染为网页 | 通过依赖安装 |
| site/ | 保存生成的 HTML、样式和脚本 | 否 |
| GitHub Actions | 在云端安装、构建和上传产物 | 维护工作流配置 |
| GitHub Pages | 托管构建完成的网站 | 通过部署任务更新 |

## 内容设计

我把“为什么做”“如何操作”“如何描述接口”分别放在不同页面，避免把所有内容堆在首页。导航路径以 docs 目录为起点，正文使用相对链接，便于本地预览与项目子路径下的在线访问。

## 自动发布的价值

把构建命令写进版本管理后，其他人可以根据同一份配置复现操作。构建使用严格模式，发生警告时先修正再发布；部署任务依赖构建任务，避免将未通过检查的输出发布出去。
